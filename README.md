A modified baskervillef font with addition of modified GFS Porson with papyrological support. That combination produces an "anglo" appearance of classical editions from 20th century as Oxford Classical Texts editions. The font can be used for philological texts with somes glyps like "combiningdotbelow" (U+0323), "notcombiningdotbelow" (privative area, U+E5CE)", etc.
